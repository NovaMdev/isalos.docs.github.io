# Plot & Business Intelligence
This menu provides data visualization tools for representing data through plots and dashboards. It includes relationship and trend charts for analyzing variable relationships and changes over time, comparison charts for evaluating differences across categories, distribution and density charts for understanding data spread and patterns, and flow charts for visualizing processes and data movement. The menu also includes Business Intelligence tools for building dashboards to track key metrics and insights.
